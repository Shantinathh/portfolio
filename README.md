# Shantinath Patil — AI Engineer Portfolio

A modern, high-performance portfolio website built for **Shantinath Patil**, showcasing expertise in Machine Learning, Deep Learning, Generative AI, and RAG systems.

## ✨ Features & Highlights

- **Interactive 3D Elements**: Powered by Three.js and `@react-three/fiber` for sleek background visuals.
- **Dynamic Animations**: Smooth scroll reveals, transitions, and micro-interactions with `framer-motion`.
- **Comprehensive Project Showcase**: Detailed breakdowns of AI/ML projects with architecture tags, key achievements, and code links.
- **Interactive AI Pipeline & Skills**: Visual representation of end-to-end ML & RAG workflows and full skill taxonomy.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop screens with dark-mode aesthetic.
- **SEO & Social Metadata**: Preconfigured Open Graph and Twitter Card tags with Google Fonts (`Inter`, `Space Grotesk`, `JetBrains Mono`).

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **3D Graphics**: [Three.js](https://threejs.org/) + [@react-three/fiber](https://r3f.docs.pmnd.rs/) + [@react-three/drei](https://github.com/pmndrs/drei)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Linter**: [Oxlint](https://oxc.rs/)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Shantinathh/portfolio.git
cd portfolio

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build & Lint

```bash
# Lint code with Oxlint
npm run lint

# Type-check and build production bundle
npm run build

# Preview production build locally
npm run preview
```
